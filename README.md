# Ruta de Consignación

App web simple para llevar registro de los productos que dejo en almacenes y dietéticas.

- Cargás tus **comercios** y tus **productos** con su precio.
- **Dejás productos** en un comercio (entrega a consignación).
- Cuando volvés, **liquidás**: cuántas se vendieron, cuántas te devuelven.
- Registrás los **pagos** y la app lleva el saldo que te deben.

Todo se guarda en el navegador del dispositivo donde la usás (localStorage).
No hay servidor ni base de datos: nada viaja a ningún lado.
En la pestaña **Datos** tenés la copia de seguridad para pasar la información de un dispositivo a otro.
